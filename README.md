# 港车北上业绩看板

纯前端看板。申请列表、续保列表、销售报表、其他数据补充和小红书/微信月报都在浏览器里读取，不上传到服务器。

## 本地运行

```bash
npm install
npm run dev
```

开发服务默认在 `http://127.0.0.1:4179`。


## 上传槽

选择文件后先预览，点最下面的「提交」才进入看板。同一批文件里如果同一个指标数值不同，会先对照，再点「确认提交」。

- 太平&人保新增、太平&人保续保：一份名单里用「保司」列区分太平和人保。可一次放多个月份，按创建时间分月。
- 其他数据补充：验车量、咨询量、SEM、Facebook。表头用 `2026-01` 这种月份。
- CTIA Sales Report：补历史月份。有名单的月份，申请、成交和保费以名单为准。
- 小红书及微信月报：内容页，含本月、环比、同比和本年累计。
- 本月行动：`.docx` 或 `.pptx`。看板读出文字，收成一句话，放在总览总结下面。

首次打开会载入仓库里的三份示例：销售报表、补充表、内容月报。名单和本月行动需要自行上传。刷新后示例会重新载入，已上传的文件需要再选一次。

## 口径

统计月按创建时间，用年份和月份两个下拉框，点确认后才切换。起保日期用于保障起期。应续保只按车牌算一套：去年同月起保的成交车牌计 1；之后出现起保更晚的成交即已续保，仍算原产品，换保司或换产品也算。下一年改按新保单的起保月。看板上从去年同月展示到本月，并带上之后两个月。等效先认 2026 年各月应续保为 0，直到名单算出别的数。投保产品文案与保额不一致时，以交强险、商业险、座位险保额为准。

同一车牌、同一业务、同一自然月：

- 有几笔「支付成功」就计几笔成交和申请。
- 「支付成功」和「已上传证明」同时存在时，只保留支付成功。
- 只有「已上传证明」时，多行也只计一笔。
- 只有「已申请」时，计一笔申请、零笔成交。续保没选中的套餐不另计次数，保费只取成交行。

金额用港币总保费。商业险保费留空按 0。佣金 = 港币保费 × 佣金率。日均成交按自然日计算，含工作日和非工作日，并分成新增日均成交和续保日均成交。

线下：天水围，以及 2025 年 10 月及之前的新田。线上：官网、谷歌 SEM、验车网站、Facebook、电邮，以及 2025 年 11 月及之后的新田。

各产品佣金率可在「口径」页修改。
